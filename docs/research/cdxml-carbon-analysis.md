# Carbon connectivity without a drawing layout

The public CDXML property definitions identify an omitted NodeType as Element and an omitted Element as carbon. When NumHydrogens is absent, the file specifies the minimum hydrogen count that satisfies the atom's valence. Bondline uses these defaults here only for a neutral, natural-isotope carbon with no radical and a completely known set of integral bonds. An explicit attached count must match the four-valence graph. Each omitted value remains absent in the saved file. [Node type](https://iupac.github.io/IUPAC-FAIRSpec/cdx_sdk/properties/Node_Type.htm) · [Element](https://iupac.github.io/IUPAC-FAIRSpec/cdx_sdk/properties/Node_Element.htm) · [Hydrogens](https://iupac.github.io/IUPAC-FAIRSpec/cdx_sdk/properties/Atom_NumHydrogens.htm) · [Bond orders](https://iupac.github.io/IUPAC-FAIRSpec/cdx_sdk/properties/Bond_Order.htm).

The supported shape has a single direct page, one or more nonempty direct fragments, elemental nodes and explicit single, double or triple bonds. The ordinary elemental reader validates local object identities and resolves each endpoint to its own fragment. Optional positions and the producer's name do not determine chemical identity. Direct font and colour tables with ordinary resource fields are accepted after validation. Every element and attribute must have a recognized owner and spelling. A plain CDXML doctype is allowed. External declarations, groups, unknown nodes and attributes, query bonds, stereochemical annotations and unresolved or conflicting valence remain outside this chemistry proof.

Analysis checks the exact model associated with the original source. Paper rendering, atom selection, authoring, coordinate layout and format conversion retain their previous eligibility checks. Same-format Save preserves every original byte. [Independent corpus](../corpus/README.md) · [Source-preserving XML syntax](https://www.w3.org/TR/xml/#NT-doctypedecl).
