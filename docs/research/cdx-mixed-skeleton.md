# Printed heteroatoms on skeletal CDX paper

Reviewed 2026-11-20. The public Node specification assigns a direct child Text to that Node's drawing. Element and NumHydrogens carry chemical information separately. An omitted Element denotes carbon and the published H rule uses the minimum needed for valence when no count was recorded. Bondline uses that rule only for the hidden neutral carbon subset of this preview. A missing H on a printed atom leaves the binary label outside the display proof. [Node](https://iupac.github.io/IUPAC-FAIRSpec/cdx_sdk/Node.htm) · [Element](https://iupac.github.io/IUPAC-FAIRSpec/cdx_sdk/properties/Node_Element.htm) · [attached H](https://iupac.github.io/IUPAC-FAIRSpec/cdx_sdk/properties/Atom_NumHydrogens.htm)

An explicitly labelled non-carbon atom and an unlabelled carbon can share a Fragment on one Poster page. A qualifying source accounts for every object and property on the page. Supported bonds are single with an explicit width and margin on white paper. The existing FontTable, ColorTable, font-ID/ordinal, UTF-8, explicit run style, chemical body and fixed-point box checks apply to each printed label. A rectangle encloses the text's depiction. Element anchoring, the accepted Roboto outlines and stroke-to-outline clearance are Bondline's documented placement policy. The two active/dormant carbon flags keep their existing local binary implied-boolean meanings, and the renderer checks current geometry and the full page. [Bounding box](https://iupac.github.io/IUPAC-FAIRSpec/cdx_sdk/properties/BoundingBox.htm) · [Existing boxed-label proof](cdx-atom-label-preview.md) · [Skeletal policy and implied flags](cdx-skeletal.md) · [IUPAC drawing recommendations](https://iupac.qmul.ac.uk/drawing/drawing.html#GR211)

The display-only grant requires an exact current CDX source and model. It supports ordinary view, chemical hit testing, capture and same-format unchanged Save. Unrenderable chemical text remains available through the prior data-only path when that path can decode it, including its literal Unicode body. Label editing or translation would require a separate source-preserving proof for the affected position and dependent text rectangle.
