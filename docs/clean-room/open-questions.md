# Open questions

- Public 26.1 release notes are available, but no full public 26.1 menu/palette reference
  was located. The 573-row cited baseline in parity-checklist.md covers explicit guide
  controls and shortcut tables plus 26.x desktop deltas; remaining context menus, unnamed
  glyphs and platform-specific controls prevent a complete modern-inventory claim.
- G25 atom table p.68 assigns k to potassium, while p.69 assigns k to sprouting sulfonyl.
  Do not invent precedence. Bond table p.73 and the explicitly modified table p.75 assign
  4 to ring fusion, while the legacy drawing paragraph p.86 describes quadruple-bond input.
  The modified table is positive evidence for its stated default; modern context/default
  differences still need documentation. Example-only bond v at p.74 is not defined in its table.
- G25 uses Color/Colors, Actual/Actual size and Show Document/Fit to window inconsistently.
  Shortcut action labels do not establish exact modern submenu nesting. Most key tables
  use CTRL without a general macOS mapping; only explicitly documented Mac bindings and
  independently verified Bondline behavior may be claimed. Keyboard-layout behavior needs tests.
- Several attachment-point and BioDraw glyphs share labels in the public guide. Their
  exact palette variants remain unresolved. Never inspect installed toolbar/hotkey XML,
  help bundles or program binaries to fill these gaps; use further public documentation.
- The archived CDX SDK does not establish every modern extension. Preserve unknown data.
- Native declared license closure now passes all three desktop targets. Native Windows/Linux
  execution and complete release notice assembly remain; every dependency upgrade needs new
  closure/source/asset evidence. Crate labels alone are insufficient.
- CPU/GPU raster tolerances and human-approved goldens remain to be established before claims.
- Editable Office embedding and modern naming/prediction behavior need public evidence.
- REA 6.9.0 was run externally using an existing Node 26.12.1 installation without changing
  the selected system runtime. It remains a development tool, outside the shipped application.
- Before the M5 WebAssembly release, resolve the candidate browser graph's Unicode-licensed
  identifier data. Current native license gates do not imply browser approval.
