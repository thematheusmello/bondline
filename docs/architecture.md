# Architecture

The [CDX caption editor](research/cdx-caption-edits.md) uses the same ordered
source records as the caption reader to resolve a stable TextId. The encoder
preserves raw styles, updates proven starts and patches one property. Captions
and atom labels share complete candidate re-import and immutable edited
backing. Native view, history and Save consume the certified snapshot.

The [CDX boxed-label preview](verification-cdx-atom-label-preview.md) shares
the verified Poster and whole-page scene checks with caption preview and
the explicit connected-bond checks with CDXML. Source kind and exact
model equality authorize display. The [existing-label writer](research/cdx-atom-label-edit.md)
edits scoped properties and re-imports the complete candidate before
attaching its bytes to the immutable current model. The [implicit Element path](research/cdx-implicit-element.md)
uses a checked insertion before the same Node's explicit H record when required.
History owns original and
current backing. Save borrows the bytes certified for its captured snapshot.
Other CDX data remains available through the earlier projection.

The [CDX Node label projection](verification-cdx-node-labels.md) reads a
direct child Text with explicit styles through the shared caption string
reader. The elemental layout still owns source identity and the numeric
graph. Candidate rejection preserves the earlier diagnostic. The existing
model keeps both literal values and raw source for byte-exact unchanged Save.
Display, editing and conversion keep their existing authority checks.

The [plain CDX bond projection](verification-cdx-plain-bonds.md) reuses existing
BondOrder/DoublePosition. One checked private field reader maps binary1/2/4 and six
explicit directed side values, leaving absent position Unspecified. Both owner/admitted
lists enforce the three new Bond properties. Only absent/Solid styles pass; explicit
secondary style/position is Double-only. Raw automatic/manual provenance stays in the
immutable complete source, with no writer/default positioning or display permission.
Existing registry49/adapters/history/source-loss checks consume the data unchanged.
Standalone font/colour resources and complete Text/styles/source certificates still
precede faithful CDX rendering or chemical edits.

The [literal CDX projection](verification-cdx-literal-atom-metadata.md) populates existing
Atom isotope/charge/radical/explicit-H fields without adding model or adapter types.
Both global owner classification and local Node properties enforce the same four tags;
absence and original source bytes remain distinct. Four-byte Charge uses the published
property-specific signed high-byte rule. Missing H is unresolved, with no chemical
inference. StoredDocument keeps its old incomplete/full/display/edit/loss boundaries;
unchanged Save borrows source and model drift refuses CDX output until restored. The
existing detached page/history edit remains model-only. CLI/MCP/socket/native use their
unchanged registry49; no UI/command/renderer production source changes.

classification; all neighbouring topology remains. The pure creation helper delegates to
