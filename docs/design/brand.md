# Bondline identity

The original mark is a B formed from two angular bond loops. Use the mark alone at small
sizes and the custom path wordmark when space permits. Both are MIT OR Apache-2.0, with
the [original-art notice](../../assets/brand/NOTICE.md) and hashes in the asset manifest.
The lettering is drawn from original paths and requires no font installation.

| Asset | Use |
| --- | --- |
| [Mark](../../assets/brand/bondline-mark.svg) | Teal on light backgrounds; 64-unit square master. |
| [Wordmark](../../assets/brand/bondline-wordmark.svg) | Original lettering and mark on light backgrounds. |
| [Dark mark](../../assets/brand/bondline-mark-dark.svg) / [wordmark](../../assets/brand/bondline-wordmark-dark.svg) | Mint/light ink on dark backgrounds. |
| [App tile](../../assets/brand/bondline-app-icon.svg) | White mark on a rounded teal tile. |

Primary teal is `#157576`, dark text `#25303d`, dark-surface mint `#7bd7d2` and light ink
`#f4f8fa`. Preserve the view box and aspect ratio. Use the mark alone at 16/32 pixels;
wordmark minimum box height is 24 pixels. Native labels retain the attributed Apache-2.0
Roboto for accessibility and platform consistency. The header and generated 128-pixel
window icon use the same original mark geometry without an SVG runtime dependency.

This is branding artwork, not a chemical diagram or a claim of a particular molecule.
The README banner remains an original illustration, distinct from actual app captures
and the separately approved chemical-render golden. Small-size light/dark SVG previews
were rendered with external librsvg 2.60.0 for visual review only; no renderer is bundled.
