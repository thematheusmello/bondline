# Read-only CDX atom label preview verification

The [preview contract](research/cdx-atom-label-preview.md) covers explicitly
boxed labels on a white Poster page and connected plain bonds with explicit
root styles. Unchanged Save and Save As retain every source byte.

## Independent files and RED to GREEN

Commit `6637c59` pinned six original display cases and 39 controls with
an independent binary reader and FontTools 4.61.1 geometry. The runtime
RED failed at display for all six cases. The same test accepted the 36
earlier data-only models and the three exact decode errors. The new CLI
and loopback test separately failed on the old capture refusal.

The first producer run exposed the test's incorrect JSON key spelling for
`chain_angle_degrees` in the expected cyanide model. Commit `9c08159`
corrected that key. All 45 original files and the numerical declarations
reproduced byte for byte. The qualified focused run passed 34 tests
across the new display, earlier CDX labels and captions, and existing
connected CDXML style targets. The actual CLI and loopback test also passed.

All supported files match the independent complete model and their
original resource and field ownership. Opaque bounds, colour, style,
alignment, disagreement, unknown records and malformed scopes keep the
earlier models or errors. Cropping cannot expose part of an unproved page.
Read-only preview revokes on detached model drift, and exact restoration
resumes display and original-source Save.

## Geometry and command adapters

At 200% the independent glyph bounds match the opaque label extents to
within 2.5 pixels. Bond pixels have the declared centers and nominal
widths of the Double and Triple rails within pixel sampling tolerance.
Atom and rail hits return the
expected typed IDs. The explicit automatic and manual Center records keep
different bytes and produce the same model and pixels.

All six actual 1024 × 1024 CPU and Metal captures match byte for byte.
Independent FreeType via Pillow 12.3.0 rasterized the declared
FontTools glyphs with 8× supersampling. Half-coverage colour mask
intersection over union ranged from 0.941003 to 1.0 across 16 labels.
The comparison establishes label placement with Bondline's bundled font.
Human golden approval and reference-specific rendering remain open.

RDKit 2026.09.2 read the actual binary connected cases with the declared
atom elements, literal H counts, bond directions and orders. It reported
H₂O, CO₂ and CHN. These checks concern the numeric graph. The entry points
for authored label editing and page resizing refused and preserved
engine state through authenticated loopback and initialized stdio MCP.
MCP also saved and reopened exact Unicode cyanide source with identical
capture bytes. The registry remains byte-identical at 49 commands, and
the catalogue stays at 16 active bindings and 124 planned entries.
