## Delivered contract

The34th command, `ui.atom_label`, queues or cancels one exact target. It is closed/tagged
by `action`, with revision and positive target/request IDs. Headless hosts refuse with
`ui_unavailable`. Open changes no authored state/history/baseline/view/tool. The optional
request snapshot carries initial literal fields and computed currentness; an operation
marker wakes an attached host only after the existing control publication boundary.
There is no fake `ui.file` atom target or empty-target control binding. Default discovery
counts stay20 Drawing/14 SDF/10 raw SMILES.

Fresh Alt-primary input uses existing atom/label picking and the shared registry. The
form names its exact page/fragment/atom and supplies Element, Attached hydrogens, Apply
and Cancel. Exact-case symbols use the existing118-element catalog; H is explicit
ASCII decimal0..65535. Unknown H starts blank, not zero. Physical H plus attached H
refuses. Two/five-byte draft limits reuse the checked SDF TextBuffer; its old65536-byte
constructor remains unchanged. No charge, isotope, radical, alias, neighbor correction
or general valence inference is introduced. Foreign/incomplete sources keep their guards.

The request captures weak source/revision/generation, opaque file-association identity,
file/close/view epochs and tool state. Stale drafts remain copyable/editable but cannot
Apply. Apply revalidates under the same Engine lock and dispatches `atom.set_label` once;
success or validated no-op retires that presentation. Cancel can release a stale draft;
exact host retirement after committed close authorizes no edit, Save or close ACK.
Host detachment clears the request. No new worker, scheduler or dependency is introduced.

The host records actual displayed field galleys/response geometry and button IDs. It
handles only input through the earliest Apply/Cancel activation before dispatch; later
text cannot change an earlier Apply. The action-prefix router uses public pinned SDK
selection/events and current field focus. Per-widget whole-reject bounds apply to paste
and AX replacement. A refused Apply retains at most the last explicitly targeted valid
replacement per field: two events/seven value bytes, once-only, with no generic key replay.
Frame-start fencing survives dismissal. Existing local file/SDF owners defer the form;
Save/close wait for explicit resolution. Engine poison retains recovery text.
