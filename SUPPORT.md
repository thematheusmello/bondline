# Getting help with Bondline

Read the [README](README.md) and [current status](STATUS.md) for the delivered
features and limitations. The [development guide](docs/development.md) covers
building, test tools and platform packages. The
[control protocol](docs/control-protocol.md) covers CLI, MCP and authenticated
loopback operations; [native file workflows](docs/native-file-ui.md) describe
the current desktop Open, Save and close behavior.

Use GitHub Issues for help:

- [Report a bug](https://github.com/thematheusmello/bondline/issues/new?template=bug_report.yml)
  with a reproducible failure.
- [Request a feature](https://github.com/thematheusmello/bondline/issues/new?template=feature_request.yml)
  by describing the chemical workflow and desired result. The
  [roadmap](ROADMAP.md) and [parity checklist](docs/parity-checklist.md) show existing plans.
- [Ask a question](https://github.com/thematheusmello/bondline/issues/new)
  when you need help or are unsure which category fits.

Useful diagnostics include the commit or build identifier, operating system and
architecture, interface used, exact steps, expected result and actual result.
For rendering problems, include the GPU/adapter if known. Short error messages or
sanitized logs help; you do not need to diagnose the code before reporting a problem.

Share only files you are allowed to make public. A small original example is
preferable to a confidential research document. Reports are welcome without an
attachment if you cannot share the affected file. Before sharing logs or screenshots,
remove credentials and loopback session tokens, and redact sensitive paths or chemical data.
Do not upload proprietary reference binaries or copied asset libraries.

For suspected security vulnerabilities, use the private channel in
[SECURITY.md](SECURITY.md), without posting technical details in a public issue.
To contribute a fix or research, see [CONTRIBUTING.md](CONTRIBUTING.md).
