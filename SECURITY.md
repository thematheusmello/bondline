# Security policy

Report suspected vulnerabilities through
[GitHub's private vulnerability reporting form](https://github.com/thematheusmello/bondline/security/advisories/new).
Private reporting is enabled for this repository. GitHub explains the process in
[Privately reporting a security vulnerability](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/report-privately).

Do not put exploit details, proof-of-concept payloads, credentials or confidential
chemical files in public issues or pull requests. Use the private report for:

- The exact Bondline commit or build, operating system and affected interface.
- The security impact and steps needed to reproduce it.
- A minimal original or redistributable input, when relevant, with sensitive data removed.
- Any mitigation or proposed fix you have identified.

Bondline is in active development and has no published stable-version support
schedule. Identify the affected revision rather than assuming a release is supported.
Report ordinary bugs and setup questions through [SUPPORT.md](SUPPORT.md).
